# Maria Paula — Portfólio

Portfólio pessoal em React 19, TypeScript e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para produção:

```bash
npm run build
npm run preview
```

Projetos ficam em `src/data/projects.ts`. Enquanto a lista estiver vazia, a seção mantém o estado atual com o convite para o GitHub.
